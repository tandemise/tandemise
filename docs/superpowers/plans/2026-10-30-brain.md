# The Brain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each project links to one git repository, its brain, that holds the factory definition and what the project has learned. Corrections become short scoped lessons, the next run loads the relevant ones and shows which, and lessons that keep helping become rules through an evaluated PR to the brain.

**Architecture:** The daemon owns a clone of the brain under `TANDEMISE_HOME/brains/<workspaceId>/`. `factory/` is the P15 setup tree, read and written by the existing codec. Once a project is linked, the database's factory rows are a cache of `factory/` at `lastPulledSha`. Memory is an append-only JSONL ledger, one file per writer per month, folded by a pure function in `@tandemise/domain`. Every attempt reads the brain at one pinned commit through `git show`. The context compiler gets rules, budgeted lessons and an index. The `brain.*` gateway tools fetch detail on demand, and `runs.brain` records what the run knew. Learning signals (holds, rejections, gate fail-then-pass, "Remember this", `brain.propose`) feed a reflector whose structured output `BrainService` validates, scrubs and appends. Promotions are classified by code from the diff, gated by P3b evals the proposer can't see, and either fast-forwarded (small, opted in, passed) or opened as a PR.

**Tech Stack:** TypeScript, Node 22, git (system binary), `gh` CLI, better-sqlite3, zod, `yaml`, React 18, Electron 44. No new third-party dependency.

**Spec:** `docs/superpowers/specs/2026-10-30-brain-design.md` (binding; read it first, this plan argues from it). Related: `2026-10-30-hold-and-interact-design.md` "Record (for #51)" and `2026-10-30-intake-design.md` §6.2 / §9 (`tracker.yaml`, `intake.yaml`).

## Global Constraints

- Layer rules hold (`npm run check:boundaries`):
  - the pure parts (`brain/ledger.ts`, `brain/classify.ts`, `brain/select.ts`, `brain/scrub.ts`) live in `@tandemise/domain` and import only `@tandemise/shared` and zod;
  - YAML (`brain.yaml`, `gates.yaml`, `mcps.yaml`) is parsed in `@tandemise/application`, which already depends on `yaml` (the codec does);
  - `BrainRepoPort` and `BrainHostPort` are declared in `packages/domain/src/ports/brain.ts`, so `execution-local` (git) and `integration-github` (gh) implement them without importing the application layer, the way `PullRequestSnapshotPort` is declared in the domain and implemented by `GhPullRequestSnapshots`;
  - the renderer imports `@tandemise/*` as types only.
- **Migration numbering is fixed:** hold-and-interact is 022, the brain is **023**, intake 024, relay coordination 025. `assertOrdered` (`packages/persistence/src/migrations/index.ts`) refuses a gap, so the brain's first PR merges after #50's 022 is on `main`. Every brain table and column ships in 023, in Task 2, including the ones later steps use. Migration 023 is additive only, and never rebuilds a table.
- **The brain never blocks work.** A failed clone, pull, push, reflector or promoter is logged, shown in the Brain section in plain words, and work continues from the local clone (spec §4).
- **Append-only by construction.** Ledger files are written only through `BrainWrite { mode: 'append' }`, which the git adapter implements with an `O_APPEND` open. No code path rewrites or deletes a ledger line. The check proves it with a byte-prefix comparison.
- **Nothing from `evals/` reaches an agent, the reflector or the promoter.** No `brain.*` tool, prompt, worktree, `--add-dir` or model input reads under `evals/`. The brain clone is never inside a worktree.
- Every text the daemon writes into the brain goes through the P15 `Scrubber` (factory files) or `scrubForBrain` (ledger, rules, decisions). Personal fields never enter the brain: secrets, runtime profiles and routing, staffing, concurrency ceilings, `enabled` switches, notification settings, and absolute paths.
- Eval trial missions (`isTrialMission`) produce no ledger events, votes, candidates or history, and never call `brain.propose`.
- Unmeasured values are `null`, never 0. A reflector pass with no usage reported has `costUsd: null`.
- Shared files that another feature is editing in parallel (`packages/application/src/tokens.ts`, `packages/application/src/engine/task-executor.ts`, `apps/desktop/src/renderer/src/screens/mission/TaskDetail.tsx`) get **additive, minimal** edits only: new optional deps, one call site, one rendered component. Put the logic in new brain files. `tokens.ts` is not edited at all; brain tokens live in `packages/application/src/brain/tokens.ts`.
- UI copy says "you", uses plain verbs, never shows raw enums, tool names or SHAs without context. Colours come only from `palette.css`/`theme.css`, with no `var()` fallbacks. Classes are BEM and state lives in `data-*`.
- Refusals are `TandemiseError('CONFLICT' | 'VALIDATION', <sentence>)` in the daemon's own words, and the UI shows them verbatim.
- Offline checks never touch the network. A "remote" is a local bare repository (`git init --bare -b main`), and `gh` is a fake script first on `PATH` that records its argv to a JSON-lines file and prints canned output.
- Repo artifacts are in English. Commits and PR titles are Conventional Commits with a lowercase subject. Run `npm run ci` before each PR.

## Review Focus

1. **The cache refresh can't loop or leak.** Applying `factory/` to the database after a pull must not write through back to the brain. It must leave this machine's routine and issue switches, routing, staffing and profiles exactly as they were. Pinned in Task 6.
2. **Ledger convergence.** Two clones that append and vote concurrently, push (one is rejected, rebases and pushes again) and pull end with equal folds and no rebase conflict on `memory/ledger/`. Every ledger file is a byte prefix of its next version. Pinned in Tasks 8–9.
3. **One brain commit per attempt.** The prompt, `brain.read` and `runs.brain.sha` all use the attempt's `brainSha`. A retry in the same round reuses it, and a pull during the run changes none of them. Pinned in Tasks 10–11.
4. **Classification and eval isolation.** A diff that removes or rewords a line, touches front matter or a workflow, or relaxes an approval is never `small`. A diff touching `evals/` is refused. No model input or tool output contains a byte from `evals/`. Pinned in Tasks 13–14.
5. **Scrubbing on every write path.** A fake token placed in a hold diff, a reflector output, a rejection note, "Remember this" and an agent proposal never appears in `git log -p --all` of the bare remote, and an absolute path outside a repository is refused. Pinned in Tasks 5, 9 and 12.

## Calls this plan makes within the spec

1. **Port placement.** `BrainRepoPort` and `BrainHostPort` are declared in the domain, not the application layer. That is the only way `execution-local` and `integration-github` (layer 4) can implement them, and it matches `PullRequestSnapshotPort`.
2. **Migration 023 holds everything.** Every brain table ships in one migration in step 1, because 024 and 025 are taken and migrations must be contiguous.
3. **Reflector and promoter spend count toward P8 limits** through the `measured_usage` view over `usage_records` and `brain_passes`. A pass has no `runs` row to hang a usage record on.
4. **Eval cost uses the scorecard's mean.** Spec §8 says median; the P3b scorecard has no median, so the mean stands in.
5. **Confirms and votes carry an optional mission title**, so "confirmed across N missions" needs no local ids.
6. **`factory/intake.yaml` is reserved** beside `tracker.yaml`, confirming the intake spec's provisional name. Both are carried byte for byte and are structural in classification.
7. **The knowledge fields stay in `factory/tandemise.yaml`** (P15 byte-identity, spec acceptance 5). On a linked project the compiler ignores them in favour of `memory/rules/project.md`; they are what an unlink falls back to.
8. **Learning signals are mined from the live event bus.** A signal that arrives while the daemon is down is not mined later. The reflector is best-effort by design (spec §6).
